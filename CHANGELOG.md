# Changelog

## 0.1.0

### Added
- Installable Python package and `llokim` command
- `--help`, `--version`, and `doctor` commands
- JSON configuration loading and validation
- Safe `journalctl` collection with time, limit, and priority filtering
- Normalized `LogEvent`, `Finding`, and `AnalysisReport` models
- Deterministic severity, service, repetition, and rule analysis
- Authentication, service, kernel, storage, network, and hardware patterns
- Terminal, JSON, and plain-text reporting
- `analyze` command with time, limit, no-AI, JSON, and export options
- Optional local Ollama interpretation with graceful fallback
- Credential redaction and untrusted-log prompt delimiters
- Synthetic unit tests and security tests
- Synthetic benchmark utility
- Architecture, privacy, security, and development documentation
